# pi_arctan

Machin型（arctan型）の円周率公式を探索するRust製ツールです。

```text
pi/4 = sum(c_i * atan(1 / n_i))
```

候補となる公式は、ガウス整数を使って厳密に検証します。数値計算には整数の固定小数点演算を使用するため、10,000桁のベンチマークも浮動小数点の丸め誤差に依存しません。

## 使い方

### 公式の検証

古典的なMachinの公式を検証し、10,000桁の計算時間を測定します。

```sh
cargo run --release -- verify '4:5,-1:239' --digits 10000
```

各項は `係数:分母` の形式で指定し、カンマで区切ります。上記の入力は次の公式を表します。

```text
pi/4 = 4 * atan(1/5) - atan(1/239)
```

### PSLQ法による探索

任意個の分母候補から整数関係を探索します。

```sh
cargo run --release -- pslq --denominators 49,57,239,110443 \
  --precision 100 --max-coeff 1000000
```

`--denominators 2-10` のような両端を含む範囲指定と、カンマ区切りを利用できます。PSLQは次のベクトルに対する整数関係を探索します。

```text
[pi/4, atan(1/n1), atan(1/n2), ...]
```

発見した関係は、ガウス整数による厳密検証に成功した場合だけMachin型公式として採用されます。

`pi/4` の係数が0の関係は、arctan項同士の従属関係です。この場合は関係に含まれる分母を1つ取り除くデフレーションを行い、縮小した基底でPSLQ探索を続けます。公式を発見した場合も参加している分母を1つ取り除き、それ以上の関係が見つからなくなるまで探索を継続します。複数の公式は発見順に出力されます。

## WebAssembly / GitHub Pages

静的Webページ一式は `docs/` に出力されています。サーバー側の実行環境やJavaScriptのビルド工程は不要です。時間のかかる探索はWeb Worker内で実行されるため、探索中も画面操作を妨げません。

Webページでは次の2種類の探索方式を選択できます。

- **厳密全探索**: 分母範囲、最大項数、係数上限の組み合わせを、ガウス整数とmeet-in-the-middle法ですべて探索します。
- **PSLQ候補探索**: 数値的な整数関係を高速に探索し、見つかった候補を厳密検証します。全探索ではありません。

厳密全探索では、実行前に左右それぞれの部分積数を計算します。いずれかが1,000万件を超える場合は、ブラウザのメモリ消費と実行時間を抑えるため探索を開始せず、範囲・最大項数・係数上限を小さくするよう案内します。

探索中は、処理済み件数、進捗率、経過時間、推定残り時間を表示します。公式は発見された時点ですぐに画面へ追加され、その後も探索が続きます。

### WebAssemblyの再ビルド

Rustコードを変更した場合は、次のコマンドでブラウザ用ファイルを再生成します。

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.127 --locked
./scripts/build-web.sh
```

### ローカルでの確認

ES ModulesとWASMを使用するため、`file://` で直接開かずHTTPサーバー経由で確認します。

```sh
python3 -m http.server 8000 --directory docs
```

起動後、ブラウザで <http://localhost:8000> を開きます。

## 探索方式の使い分け

指定範囲を漏れなく調べたい場合は厳密全探索を使用します。探索空間が大きい場合は、分母範囲、最大項数、係数上限を分割して実行すると必要なメモリを抑えられます。

広い範囲から短時間で候補を探したい場合はPSLQを使用します。ただし、PSLQは条件内のすべての公式を列挙することを保証するものではありません。
